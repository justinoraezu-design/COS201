# COS 201 – Computer Programming I
## Week 3 Practical Assignment

### Programming Language
Java

### Description
This project contains three Java programs developed for the COS 201 Week 3 practical assignment.

### Programs

1. **SimpleCalculator.java** – Performs addition, subtraction, multiplication, and division of two numbers.
2. **AverageCalculator.java** – Calculates the average of three scores.
3. **ItemCost.java** – Calculates the total cost of an item based on its price and quantity.

### Requirements
- Java Development Kit (JDK)
- Visual Studio Code

### How to Compile and Run

**SimpleCalculator**
```bash
javac SimpleCalculator.java
java SimpleCalculator
```

**AverageCalculator**
```bash
javac AverageCalculator.java
java AverageCalculator
```

**ItemCost**
```bash
javac ItemCost.java
java ItemCost
```

### Conclusion
The programs demonstrate basic Java concepts such as variables, input, arithmetic operations, and output.
